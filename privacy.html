Privacy Policy

Effective 15 October 2026 · updated 16 October 2026 (YouTube Analytics, Instagram Insights, Facebook, TikTok through Buffer, Cloudinary)

This policy covers Mika Publisher, the publishing tool of the Project: Mika YouTube channel, and this website. Mika Publisher is used only by the Project: Mika team to post the channel's own videos to the channel's own accounts and to read those accounts' own statistics. It has no other users.

What Mika Publisher accesses

When the team signs in to one of the channel's accounts, Mika Publisher receives an access token from that platform and uses it only for these actions on that same account:

YouTube (YouTube API Services)

Reading the channel's name and ID; uploading videos and setting their title, description, tags, privacy and publishing time; setting thumbnails; uploading caption files; adding videos to the channel's playlists; deleting the channel's own test uploads; reading the channel's statistics and YouTube Analytics reports (views, watch time, traffic sources, and aggregated, anonymous audience figures such as country, device, age group and gender).

Instagram

Reading the account's basic profile; publishing Reels and posts with their captions and covers; reading the account's own statistics (Instagram Insights: reach, views and aggregated, anonymous audience figures).

Facebook

Listing the Pages the signed-in team member manages and reading the Project: Mika Page's basic details; publishing Reels and videos to that Page, with their descriptions and covers, as drafts, scheduled or public; reading the Page's own statistics (Page Insights: reach, views and aggregated, anonymous audience figures).

TikTok (through Buffer)

Mika Publisher reaches TikTok through Buffer, a social media scheduling service, with the team's Buffer API key: listing the Buffer account's connected channels; publishing the channel's own videos to its TikTok account with their captions; reading those posts' statistics (views, reach, likes, comments, shares and watch time). The TikTok connection itself belongs to Buffer, under Buffer's own terms and privacy policy. A video scheduled for later is first uploaded to Cloudinary, a media hosting service, so that Buffer can fetch it at the scheduled time; it is deleted from Cloudinary once it is posted.

What is stored

The access tokens, the Buffer API key and the Cloudinary API secret are stored on the team's own computer, in a file only that computer's owner can read. Mika Publisher also keeps a local log of what it posted: the platform, the video's ID and link, and the time. Nothing is stored on any server of ours.

What is shared

Nothing. Data received from YouTube, Instagram, Facebook or TikTok is not sold, not shared with or transferred to anyone, not used for advertising, and not used to train AI models. It is used only to publish the channel's own videos and to read the channel's own statistics. To publish on TikTok, the channel's own videos and captions are sent to Buffer, which posts them; a video scheduled for later waits on Cloudinary until then.

Mika Publisher's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

Mika Publisher uses YouTube API Services. Google's handling of data is described in the Google Privacy Policy. Access can be revoked at any time on the Google security settings page.

Removing access and data

Access can be removed at any time: on Google's security settings page (above), in Instagram's settings under apps and websites, in Facebook's settings under business integrations, and for TikTok, by disconnecting the channel in Buffer or removing Buffer in TikTok's settings under security and permissions. The team deletes the stored tokens when an account is disconnected. To ask about any data, write to the address below.

This website

This website sets no cookies and runs no analytics. It is hosted on GitHub Pages; GitHub may log visits as described in the GitHub Privacy Statement.

Children

Mika Publisher is not directed at children and collects no data from them.

Changes

If this policy changes, the new version is posted on this page with a new effective date.
